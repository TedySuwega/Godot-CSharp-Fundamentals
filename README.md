Godot C# Fundamentals
Description: This repository tracks my progress in learning 2D game development using the Godot Engine (C# version). The project focuses on implementing core game mechanics, understanding the engine's architecture, and practicing clean code principles within a game development context.

Key Learning Objectives:

Setting up a Godot project with C# and .NET.

Implementing character movement and physics.

Designing levels using TileMaps.

Managing project structure and version control in a Windows environment.

Reference: This project is built following the comprehensive guide by Brackeys:
