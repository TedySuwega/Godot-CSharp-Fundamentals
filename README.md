# 🎮 Godot C# Fundamentals

This repository tracks my progress in learning 2D game development using the **Godot Engine (C# version)**. The project focuses on implementing core game mechanics, understanding the engine's architecture, and practicing clean code principles within a game development context.

---

## 🎯 Key Learning Objectives

* **Project Setup:** Configuring a Godot project with **C# and .NET**.
* **Player Mechanics:** Implementing character movement, physics, and input handling.
* **World Building:** Designing levels and environments using **TileMaps**.
* **DevOps & Workflow:** Managing project structure and version control in a Windows environment.
